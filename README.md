# Connor Vu Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

# Live site
View the portfolio [here](https://connorvu.github.io)

## Run locally

Open `index.html` in a browser, or serve this folder with a local development server.

## Pages

- `index.html` — homepage, about, selected work, skills, and contact
- `digital-art-design.html` — Digital Art & Design
- `3d-models.html` — 3D Models
- `interactive-media.html` — Interactive Media
- `physical-installations.html` — Physical Installations

## Assets and styling

- `assets/projects/` — project imagery used throughout the site
- `style.css` — layout, responsive styling, and visual system
- `script.js` — navigation and interaction behavior

Project pages use concise editorial notes where additional project details or media are still being prepared.

## Before publishing

Verify the public contact links and review project descriptions, image captions, and any remaining editorial notes.


## Responsive galleries
Project images are presented in horizontal, touch-friendly carousels. Select any image to open the larger image viewer; use Magnify to zoom, arrow controls or keyboard arrows to browse, and Escape to close. Gallery styling is maintained in `style.css`, while behavior is in `gallery.js`.
